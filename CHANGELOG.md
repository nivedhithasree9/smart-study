# Changelog

All notable changes to this project will be documented here.

## 0.3.0 - 2026-06-28

- Added Progress page for quiz attempts, scores, and document completion.
- Removed visible Settings page from the Streamlit sidebar.
- Improved MCQ generator with real JavaScript questions.
- Made quiz answers hidden until the user checks answers.

## 0.2.0 - 2026-06-28

- Added cleaner note-style summaries.
- Filtered noisy PDF headers, page numbers, and code-heavy snippets.
- Improved flashcards with concise study definitions.

## 0.1.0 - 2026-06-28

- Added Streamlit MVP.
- Added PDF, TXT, PNG, and JPG upload flow.
- Added SQLite persistence, caching, summaries, flashcards, MCQs, search, and history.
- Added Phase 1 spec kit and AGPL license.
